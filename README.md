# BLACKOUT LAB — 정전

중학교 1학년 과학(2022 개정) 수업용 공포 협동 탈출 게임. 정전된 밤의 과학관에서 팀원들과 발전기 부품을 모아 출구를 열고 탈출한다. 괴물은 건물을 돌아다니며 소리를 듣고 빛을 본다.

## 수업에서 쓰는 법
1. 교사: 이 페이지를 TV에 띄우고 **교사 · 방 만들기** → 4자리 방 코드가 나온다.
2. 학생: 각자 폰으로 같은 주소에 들어가 **학생 · 참가하기** → 별명과 방 코드 입력. 소리를 켜고 가능하면 이어폰.
3. 교사 화면에서 팀 인원·제한 시간·괴물 속도·필요 부품 수를 정하고 **시작**.
4. 팀마다 독립된 건물에서 플레이. 교사 화면에는 모든 팀의 지도가 실시간으로 보인다.
5. **게임 종료**를 누르면 팀별 결과와 **오답 목록 + 해설**이 나온다. 그대로 띄워 놓고 해설하면 된다.

## 규칙
- 부품 상자(빨간 불)를 열면 그 방 단원의 문제가 나온다. 맞히면 부품, 틀리면 경보가 울려 괴물이 그쪽으로 오고 상자는 15초 잠긴다.
- 필요한 수만큼 모으면 배전실 발전기를 켤 수 있다(문제 1개). 그러면 출구 문이 열린다.
- 괴물은 처음 일정 시간(기본 45초) 뒤 깨어난다. 보이면 쫓아오고, 가까이서 움직이는 소리를 들으면 찾아온다.
- 사물함에 숨을 수 있다. 단, 숨는 걸 봤으면 끌어낸다.
- 잡히면 쓰러진다. 팀원이 와서 버튼을 3초 꾹 누르면 일어난다. 아무도 안 오면 45초 뒤 스스로 깨어난다. 전원이 쓰러지면 끝.

## 방과 단원
| 방 | 단원 |
|---|---|
| 물리실 | 힘의 작용 |
| 화학실 | 물질의 상태 변화 · 기체의 성질 |
| 생물실 | 생물의 구성과 다양성 |
| 열 실험실 | 열 |
| 지질 표본실 | 지권의 변화 |
| 배전실(발전기) | 과학과 인류의 지속가능한 삶 → 이후 전 단원 |

문제는 `js/questions.js` 한 파일에 있다. 형식만 지키면 문항을 바꾸거나 단원을 늘릴 수 있다.

## 조작 (1인칭)
- 폰: 화면 왼쪽을 끌면 이동(앞뒤·옆), 오른쪽을 좌우로 끌면 고개 돌리기. 오른쪽 아래 큰 버튼이 상황에 따라 상자 열기/발전기/숨기/구조.
- PC: W/S 앞뒤, A/D 옆걸음, ←/→ 또는 마우스 드래그로 회전, Space 또는 E.
- 뒤는 보이지 않는다. 발소리 방향(이어폰 좌우)과 심장박동으로 거리를 가늠한다.

## 그림 바꾸기
`img/` 폴더에 정해진 이름의 PNG를 넣으면 괴물·팀원·벽이 그 그림으로 바뀐다. 규격과 요청 문구는 `docs/art-requests.md`.

## 연결 방식
서버 없이 공개 MQTT 중계 3곳(EMQX, HiveMQ, Mosquitto)을 동시에 쓰고, PeerJS 직접 연결을 예비로 둔다. 방장(교사) 브라우저가 판정을 맡으므로 게임 중에는 교사 화면을 앞에 띄워 두어야 한다. 내용이 공개 서버를 지나므로 실명 대신 별명.

## 혼자 연습
타이틀의 **혼자 연습**은 네트워크 없이 같은 기기에서 돈다. 부품 5개, 괴물은 30초 뒤.

## 주의
어둡고 큰 소리, 갑작스러운 얼굴 장면이 있다. 교사 설정에서 "잡혔을 때 연출"을 **암전만**으로 바꾸면 얼굴은 안 나온다.

외부 라이브러리: MQTT.js, PeerJS (lib/ 폴더에 포함). 그 외 그림과 소리는 전부 코드로 즉석 생성.
