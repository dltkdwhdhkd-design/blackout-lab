# BLACKOUT LAB — 정전

중학교 1학년 과학(2022 개정) 수업용 1인칭 공포 협동 탈출 게임. 지하 격리 연구동에서 개체 K-7의 격리가 풀리고 전력이 끊긴다. 팀원들과 실험실 단말기에서 에너지 셀을 회수해 비상 발전기를 돌리고 보안 출구로 탈출한다. 괴물은 건물을 돌아다니며 소리를 듣고 빛을 본다.

## 수업에서 쓰는 법
1. 교사: 이 페이지를 TV에 띄우고 **교사 · 방 만들기** → 4자리 방 코드가 나온다.
2. 학생: 각자 폰으로 같은 주소에 들어가 **학생 · 참가하기** → 별명과 방 코드 입력. 소리를 켜고 가능하면 이어폰.
3. 교사 화면에서 팀 인원·제한 시간·괴물 속도·필요 부품 수를 정하고 **시작**.
4. 팀마다 독립된 건물에서 플레이. 교사 화면에는 모든 팀의 지도가 실시간으로 보인다.
5. **게임 종료**를 누르면 팀별 결과와 **오답 목록 + 해설**이 나온다. 그대로 띄워 놓고 해설하면 된다.

## 규칙
- 시작하면 격리 실패 연출(약 16초)이 나온다. 교사 설정에서 끌 수 있다.
- 실험실 단말기(초록 화면)에 다가가 상호작용하면 그 방 단원의 문제가 나온다. 맞히면 에너지 셀 회수, 틀리면 경보가 울려 괴물이 그쪽으로 오고 단말기는 15초 잠긴다.
- 필요한 수(기본 9개 / 전체 14개)를 모으면 비상 발전기실의 발전기를 켤 수 있다(문제 1개). 그러면 보안 출구가 열린다.
- 괴물은 처음 일정 시간(기본 75초) 뒤 움직이기 시작한다. 보이면 쫓아오고, 가까이서 움직이면 소리를 듣고, 가끔은 누군가의 기척을 느끼고 찾아온다.
- **손전등**은 켜고 끌 수 있다(PC: F 또는 우클릭, 폰: 🔦 버튼). 켜면 잘 보이지만 괴물도 12칸 밖에서 나를 보고, 모퉁이 너머라도 빛이 벽에 비친 걸 보면 그쪽으로 온다. 끄면 바로 앞만 겨우 보이고, 괴물은 나를 바라보고 있으면 6칸, 등지고 있으면 2.5칸 안에서 알아챈다. 그보다 멀어도 괴물 시야 안에 오래 있으면 의심이 쌓여 결국 들킨다. 불 끄고 멈추는 건 멀리서 지나갈 때 잠깐 버티는 수단이다. 단말기 화면과 팀원의 손전등 빛은 꺼도 보인다.
- 사물함에 숨을 수 있다. 숨는 걸 봤거나, **손전등을 켠 채 숨으면** 틈으로 새는 빛을 보고 와서 끌어낸다.
- 가만히 서 있으면 발소리가 나지 않는다. 움직일 때만 가까이 있는 괴물이 듣는다.
- 잡히면 쓰러진다. 팀원이 와서 3초 꾹 누르면 일어난다. 아무도 안 오면 45초 뒤 스스로 깨어난다. 전원이 쓰러지면 끝.
- 지도(M 또는 지도 버튼)로 연구동 구조와 내 위치, 팀원 위치를 볼 수 있다. 지도를 보는 동안은 움직일 수 없다.

## 연구동 구조와 단원
**판마다 지도가 새로 만들어진다** (`js/mapgen.js`). 방 순서와 크기, 방 안 가구, 문 위치, 막힌 복도, 단말기·사물함·발전기·출구 위치가 매번 바뀌고, 건물이 좌우·상하로 뒤집히기도 한다. 교사 화면이 정한 지도 번호로 모든 학생 기기가 같은 지도를 만든다(관제실 위쪽에 번호 표시). 교사 설정에서 "기본 지도 고정"을 고르면 예전 지도(`tools/genmap.py`)로 한다.

방 24개는 항상 있다. 줄마다 순서만 바뀐다.

| 구역 | 방 | 단말기 단원 |
|---|---|---|
| 격리동 | 격리실 A·B, 관찰 제어실, 서버실, 기록 보관실, 의무실 | 제어실·서버실: 과학과 인류의 지속가능한 삶 / 의무실: 생물 |
| 실험동 | 물리 실험실, 화학 분석실, 생물 배양실, 열 실험실, 지질 시료실 | 힘 / 상태 변화·기체 / 생물 / 열 / 지권 |
| 중앙 | 중앙 홀(시작), 회의실, 사무실, 휴게실 | — |
| 설비동 | 비상 발전기실, 기계·환기실, 탈의실, 구내식당, 자재 창고, 보안 출구 | 발전기: 지속가능한 삶 → 전 단원 |

문제는 `js/questions.js` 한 파일에 있다(단원별 18~21개, 모두 139개). 형식만 지키면 문항을 바꾸거나 단원을 늘릴 수 있다.
- 단말기를 열 때마다 **보기 순서를 섞는다.** 결과표의 오답은 원래 보기로 표시된다.
- 교사 기기가 최근에 나온 문제(최근 160개)를 기억해 두고, **다음 판에서는 안 나온 문제부터** 낸다. 한 판 안에서는 같은 문제가 다시 나오지 않는다.

## 조작 (1인칭)
- PC: 화면을 한 번 클릭하면 커서가 잠기고, 그다음부터는 마우스만 움직이면 시점이 돈다(위아래도 조금). W/S 앞뒤, A/D 옆걸음, 왼쪽 클릭 또는 E/Space 상호작용, 우클릭 또는 F 손전등, M 지도, Esc 커서 해제. 문제가 뜨면 커서가 자동으로 풀린다.
- 폰: 화면 왼쪽을 끌면 이동, 오른쪽을 좌우로 끌면 고개 돌리기. 오른쪽 아래 큰 버튼이 상황에 따라 셀 회수/발전기/숨기/구조, 그 위 🔦 버튼이 손전등.
- 뒤는 보이지 않는다. 발소리 방향(이어폰 좌우)과 심장박동으로 거리를 가늠한다.
- **설정(⚙)**: 타이틀 화면과 게임 화면 오른쪽 위. 전체 음량, 배경음(웅웅거림·심장박동), 마우스 감도, 터치 회전 감도, 마우스 위아래 반전, 진동. 기기마다 저장된다. 게임 중에 열면 그동안 캐릭터는 멈춘다.
- 패드·폰에서 두 번 탭이나 두 손가락으로 화면이 확대되지 않게 막아 두었다(이동과 시점을 두 손가락으로 동시에 쓰기 때문). 별명·방 코드 입력칸도 눌렀을 때 확대되지 않는다.

## 그림 바꾸기
`img/` 폴더에 정해진 이름의 PNG를 넣으면 괴물·팀원·벽이 그 그림으로 바뀐다. 규격과 요청 문구는 `docs/art-requests.md`.

## 연결 방식
서버 없이 공개 MQTT 중계 3곳(EMQX, HiveMQ, Mosquitto)을 동시에 쓰고, PeerJS 직접 연결을 예비로 둔다. 방장(교사) 브라우저가 판정을 맡으므로 게임 중에는 교사 화면을 앞에 띄워 두어야 한다. 내용이 공개 서버를 지나므로 실명 대신 별명.

## 혼자 연습
타이틀의 **혼자 연습**은 네트워크 없이 같은 기기에서 돈다. 에너지 셀 5개, 괴물은 연출 끝나고 30초 뒤.

## 주의
어둡고 큰 소리, 갑작스러운 얼굴 장면이 있다. 교사 설정에서 "잡혔을 때 연출"을 **암전만**으로 바꾸면 얼굴은 안 나온다.

외부 라이브러리: MQTT.js, PeerJS (lib/ 폴더에 포함). 괴물·얼굴 그림은 img/ 폴더(교사 제공), 그 외 그림과 소리는 전부 코드로 즉석 생성.
